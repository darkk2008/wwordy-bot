# wwordy-bot

Telegram-бот проекта **wwordy**. Его голос — **Wizzy**, волшебник слов. Бот показывает слово, вы нажимаете **✅ Знаю**, **❌ Не знаю** или **⭐ Сохранить**, а `/saved` показывает все сохранённые слова.

Это отдельный проект: свой репозиторий и свой сайт на Netlify. С основным проектом его связывают только одинаковые слова (200 слов, A1–B2, 18 языков) и одинаковое имя.

## Что умеет бот

| Команда | Что делает |
|---|---|
| `/start` | Выбор изучаемого языка, родного языка и уровня (A1, A2, B1, B2 или все), затем первое слово |
| `/word` | Следующее слово |
| `/saved` | Сохранённые слова списком, по 10 на странице, с кнопками «листать» и «удалить» (🗑) |
| `/stats` | Сколько слов знаю, учу, новых и сохранено |
| `/language` | Сменить язык или уровень. Прогресс для каждого изучаемого языка хранится отдельно |
| `/app` | Открыть wwordy как Mini App внутри Telegram |
| `/help` | Список команд |

- **Карточка:** перевод спрятан под спойлером, его можно открыть нажатием. После ✅ или ❌ карточка раскрывается, и бот сразу присылает следующее слово.
- **⭐ Сохранить** не переключает слово: можно сохранить и потом нажать «Знаю» или «Не знаю».
- **Выбор слов:** новые слова показываются чаще, слова с «Не знаю» возвращаются реже новых, а известные не показываются. Когда все слова уровня известны, бот поздравляет и предлагает повторить всё.
- **Язык бота:** русский, узбекский или английский, по родному языку, который вы выбрали. Узбекские тексты стоит показать носителю языка.

## Как запустить, шаг за шагом

### 1. Создайте бота в Telegram
1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Имя: `wwordy`. Username должен заканчиваться на `bot`, например `wwordy_bot` (если занят, подберите `wwordybot` или `wwordy_app_bot`).
3. BotFather пришлёт **токен** вида `123456:ABC...`. Это пароль от бота, никому его не показывайте и не кладите в Git.
4. По желанию: `/setuserpic` и загрузите логотип wwordy.

### 2. Проверьте на своём компьютере (не обязательно, но удобно)
```bash
cd wwordy-bot
npm install
cp .env.example .env      # затем откройте .env и впишите TELEGRAM_BOT_TOKEN
npm test                  # 54 теста
npm run local             # бот заработает, пока терминал открыт
```
Откройте своего бота в Telegram и отправьте `/start`. Остановить: Ctrl+C. Прогресс сохраняется в `.data/users.json`.
Локальный режим отключает вебхук, поэтому после него снова запустите `npm run webhook` (шаг 4).

### 3. Выложите на Netlify (отдельный сайт)
1. Создайте на GitHub новый репозиторий, например `wwordy-bot`, и запушьте туда эту папку.
   ```bash
   cd wwordy-bot
   git init -b main
   git add -A
   git commit -m "wwordy bot"
   git remote add origin https://github.com/ВАШ_НИК/wwordy-bot.git
   git push -u origin main
   ```
   `.env` в Git не попадёт, он есть в `.gitignore`.
2. В Netlify: *Add new site → Import an existing project*, выберите этот репозиторий. Команду сборки оставьте пустой, настройки подхватятся из `netlify.toml`.
3. В *Site configuration → Environment variables* добавьте:
   - `TELEGRAM_BOT_TOKEN`: токен от BotFather
   - `TELEGRAM_WEBHOOK_SECRET`: любая случайная строка (получить: `openssl rand -hex 24`)
   - `WEBAPP_URL`: адрес приложения, например `https://ваш-домен.com/app/` (можно добавить позже)
4. Нажмите *Deploy*. Когда сайт заработает, откройте его адрес: должна быть надпись «wwordy bot is running ✨».

### 4. Подключите бота к сайту
В `.env` впишите те же `TELEGRAM_BOT_TOKEN` и `TELEGRAM_WEBHOOK_SECRET`, а также `SITE_URL` (адрес Netlify-сайта бота) и `WEBAPP_URL`. Затем:
```bash
npm run webhook
```
Скрипт подключит вебхук, задаст имя, описание и список команд (на английском, русском и узбекском) и поставит кнопку меню **wwordy**, которая открывает Mini App. В конце он напечатает состояние вебхука: ошибок быть не должно. Откройте бота и отправьте `/start`.

## Mini App

Кнопка меню «wwordy» рядом с полем ввода и команда `/app` открывают ваше веб-приложение прямо внутри Telegram. Для этого нужен только `WEBAPP_URL` (https). Вход через Telegram и общий прогресс между ботом и приложением пока не сделаны: бот и приложение хранят прогресс отдельно.

## Структура

```
netlify/functions/telegram.mjs   вебхук: проверяет секрет и передаёт обновление боту
src/bot.js                       логика бота (команды, кнопки, карточки, /saved)
src/logic.js                     выбор следующего слова, прогресс, сохранённые
src/words.js, src/data/          список слов (копия из wwordy)
src/i18n.js                      все тексты на en / ru / uz
src/store.js                     хранилище: Netlify Blobs, память, файл
src/telegram.js                  мини-клиент Telegram Bot API
scripts/                         set-webhook, local, sync-words
test/                            54 теста (Telegram подменяется, сеть не нужна)
```

## Обновить список слов
Если вы изменили слова в основном проекте wwordy:
```bash
npm run sync-words -- ../wwordy
npm test
```

## Данные и приватность
Бот хранит для каждого пользователя: Telegram ID, выбранные языки и уровень, какие слова он знает, не знает и сохранил. Ничего больше (ни имени, ни сообщений) не записывается. Добавьте это в политику конфиденциальности основного сайта и сообщите, что данные можно удалить по запросу (удаление: ключ `u:<telegram id>` в хранилище Blobs `bot-users`).

## Если что-то не работает
- **Бот молчит.** Запустите `npm run webhook` ещё раз и посмотрите последнюю строку `Telegram says: ... last_error=...`. Частые причины: неверный `SITE_URL`, разные значения `TELEGRAM_WEBHOOK_SECRET` в Netlify и в `.env`, сайт ещё не задеплоен. После смены переменных в Netlify нужно сделать *Deploy → Trigger deploy*.
- **`npm run local` пишет ошибку про конфликт.** Telegram разрешает только один способ получения обновлений. Запустите `npm run webhook:delete` и повторите.
- **Логи функции:** Netlify → *Logs → Functions → telegram*.

## Ограничения
- Всего 200 слов на языковую пару, так что слова будут повторяться. Список расширяется через основной проект (`sync-words`).
- Бот работает только в личных чатах, не в группах.
- Если один человек быстро нажимает кнопки с двух устройств одновременно, прогресс может записаться не полностью. Для личного бота это допустимо.
